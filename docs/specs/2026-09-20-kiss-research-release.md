# KISS research update and release

## Outcome

A recipient reads one current company review, opens its matching Excel model, and can follow dated links to earlier editions. Each update investigates material developments and explains whether they change the investment case. Technical receipts stay outside the reader narrative.

## Scope

1. Improve MLX within the existing finite-mine model: obtain a dated public quote, check shares, investigate sales/cost/capital/life inputs, and explicitly reflect the disclosed 2027 shutdown where support permits. Keep unverified economics illustrative.
2. Add a concise capital-allocation table and a bounded comparison with two relevant tin producers. Explain differences in currency, ownership and cost definitions. Do not fabricate Rentails economics or peer valuation multiples.
3. Save refined X queries through the existing revision mechanism. Preferred handles come only from saved user preferences. Keep broad and contrary searches, exact-post links, claim disposition and real check dates. No new research database or agent framework.
4. Bind reader Markdown, matching XLSX and coverage review with a portable edition manifest containing hashes, company, cutoff, valuation class and selected model results. Before PDF export, verify all files, dates, workbook identity and headline numbers. A partial briefing may publish; it cannot silently become a supported valuation.
5. Maintain a small current-edition index with dated links. Preserve previous editions and raw evidence.

## Non-goals

No new agents, screening engine, automatic trading, backtesting, API keys, general evidence graph, integrated three-statement engine, reverse valuation or speculative development model. Existing extraction and workbook generators remain the maintained implementation.

## Release checks

- Required reader sections exist; relative Excel link resolves to the exact manifest workbook.
- Evidence review validates its declared stage contract and company/cutoff; publication never equates declarations with semantic proof.
- Workbook company and selected scenario results agree with the release record; model values printed in the reader agree at declared display precision.
- Altered/mismatched artifacts and unsupported valuation promotion fail before PDF creation.
- A re-export preserves check dates; a research update records checks actually performed, including failures.
- Existing financial regression tests and new release mismatch tests pass; independently recalculate materially changed model snapshots and inspect PDF/workbook presentation.

## Research acceptance

Distinguish unavailable public disclosure from work not completed. Cite the exact evidence supporting changed inputs and retain explicit assumptions. Quote comparisons against illustrative values remain diagnostic, never price targets. Evaluate mine ownership, production versus payable sales, currency/units and timing before numerical changes.

## User journey

Previous edition -> public filings and X checks -> investigate material changes -> refresh existing Excel -> explain changes in reader report -> validate matching artifacts -> publish a new dated edition and update the index.

## Reuse

Financial-services model-update sequence; Dexter query refinement; existing Bird adapter; existing offline financial calculations and PDF/Excel generators. Implement only the small missing publication boundary.
