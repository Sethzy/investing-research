# Investing Research

A personal investing workspace operated through existing Codex/Claude sessions, using public web sources, authenticated X browsing, and Seth's second brain without API keys.

**Status:** design documentation only; no application, data integrations, or scheduled monitoring implemented yet.

Read the [implementation specification](docs/superpowers/specs/2026-09-20-investing-research-design.md) for the agreed scope, user journeys, upstream reuse decisions, financial modelling requirements, architecture diagrams, and acceptance checks.

The first acceptance company is Metals X (ASX:MLX). Outputs are readable Markdown and editable financial workbooks. Investment decisions remain with Seth; this project does not execute trades.
